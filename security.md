# 🔒 Política de Segurança — PortfolioHUB

## Visão Geral

Este documento descreve as práticas de segurança implementadas
no repositório PortfolioHUB de Gustavo Lisboa Gonçalves.

## Configurações de Segurança Implementadas:

### Conta GitHub

- Autenticação em dois fatores (2FA) ativada
- Senha forte configurada
- Sessões monitoradas regularmente

### Repositório

- Visibilidade: **Público** (portfólio profissional)
- Arquivo `.gitignore` protegendo dados sensíveis
- Sem tokens, chaves de API ou senhas no código
- Commits assinados

### Controle de Acesso

- Apenas o proprietário tem permissão de escrita
- Visitantes podem visualizar mas não editar
- Sem colaboradores externos com acesso de escrita

## O que NÃO está no repositório

- ❌ Senhas ou credenciais
- ❌ Tokens de API
- ❌ Chaves privadas (.pem, .key)
- ❌ Arquivos de configuração com dados pessoais sensíveis
- ❌ Arquivos de ambiente (.env)
