## 📌 O que é o PortfolioHUB?

O **PortfolioHUB** é um portfólio digital profissional centralizado, desenvolvido ao longo do **Bootcamp I do CEUB**, com o objetivo de reunir em um único repositório a trajetória acadêmica, projetos, certificações e habilidades de **Rafael Robson Nunes de Araújo**, estudante de Ciência de Dados e Machine Learning e fundador de ventures em IA aplicada.

A plataforma integra três camadas complementares:

* 🖥️ **GitHub Pages** → portfólio online com projetos e habilidades
* 🔧 **GitHub** → versionamento do código e hospedagem pública
* 💼 **LinkedIn** → integração e visibilidade profissional

> O PortfolioHUB não é apenas um portfólio  é uma demonstração prática de boas práticas de desenvolvimento, versionamento, segurança e documentação técnica.

## 🚀 Como Rodar o Projeto Localmente

### Pré-requisitos

* [Git](https://git-scm.com/downloads)
* Navegador atualizado (Chrome, Edge ou Firefox)
* Opcional: [VS Code](https://code.visualstudio.com/) + extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

---

### Passo 1 — Clonar o repositório

```bash
git clone https://github.com/rafael-robsonn/portifoliohub.git
```

### Passo 2 — Entrar na pasta do projeto

```bash
cd portifoliohub
```

### Passo 3 — Abrir o site

**Opção A — Direto pelo navegador:**

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

**Opção B — Via VS Code com Live Server (recomendado):**

```bash
code .
```

1. Instale a extensão **Live Server** no VS Code
2. Clique com o botão direito no `index.html`
3. Selecione **"Open with Live Server"**

**Opção C — Acessar online (sem instalação):**

```
https://rafael-robsonn.github.io
```

### Passo 4 — Explorar o repositório

```bash
ls -la

cd Apresentações/    # Slides profissionais
cd documentos/       # Currículo
cd certificados/     # Certificações
```
